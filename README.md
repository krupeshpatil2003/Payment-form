
# 💳 Payment Form

A simple and responsive Payment Form built using HTML and CSS. This project collects user contact details and payment information through a clean, structured, and user-friendly interface.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Form Elements & Validation
* Responsive Design

---

## ✨ Features

* User-friendly payment form layout
* Contact information section
* Gender selection using radio buttons
* Address input using textarea
* Email and pincode validation
* Card type selection dropdown
* Card number, expiry date, and CVV fields
* Styled submit button with hover effect
* Clean and responsive design
